Module 1 : Daily Reminders

每日提醒系統架構：白名單控管 ➔ 自行填報 ➔ 後台匯流

🔐 白名單機制與前端防護設計

為什麼需要白名單（Whitelist）？

行銷團隊常面臨外包廠商、跨部門兼職人員混雜的情境。透過「主管設定白名單」：

  • 權限隔離：僅限名單內同仁填報關鍵業務指標與預算排程。
  • 個人化視圖：成員選擇自身帳號後，自動載入專屬例行事項（如 Lead 派發、投放檢查）。
  • 稽核報表：後台自動統計「應填未填」名單並於每日 10:30 發出警示。
📋 後台資料流與儲存規格

後台即時記錄結構（JSON/DB Payload）：

{
  "log_id": "REM-20261113-001",
  "user_name": "Elena (海外行銷)",
  "timestamp": "2026-11-13 09:15:22",

支援整合 Google Sheets API、Notion 知識庫或企業內聯 ERP 資料庫。

Module 2 : Meeting Minutes Standard

會議紀錄系統架構：拒絕會議遺忘，沉澱高價值資產

📐 結構化會議欄位規格
  • 基本資訊標籤：會議主題、日期、出席人、專案分類（如動力電池、工商業儲能、展會）。
  • 核心決策摘要：明確記錄討論後的共識，避免無休止的重複討論。
  • 行動指派（Action Items）：嚴格要求「唯一負責人」＋「可交付成果驗收標準」＋「截止時間」。
📊 後台管理核心能力

後台提供之管理與回溯功能：

  • 全文搜尋與標籤過濾：可依專案名或關鍵字（如「歐盟電池法」）一鍵調閱歷史紀錄。
  • 待辦事項看板對接：自動將紀錄內的 Action Items 拋轉至 Jira、Trello 或 Notion 看板。
  • 修改稽核軌跡：記錄最後編輯人與版本差異，確保數據一致性。

Implementation Roadmap

三大系統後台落地技術選型建議

🚀 敏捷輕量方案 (No-Code/低代碼)

適合 1~2 週內快速上線：

  • 前端：Notion Database 或 Airtable 表單。
  • 後台記錄：直接利用 Airtable 視圖進行權限分流與白名單鎖定。
  • 提醒觸發：串接 Slack / LINE 機器人自動發送未交提醒。
🏢 企業級專屬方案 (Full-Stack)

適合長期資產沉澱與資料安全：

  • 前端：Vue / React 單頁應用程式（SPA）。
  • 後台資料庫：PostgreSQL (Supabase) + SSO 企業單一登入白名單驗證。
  • 報表大屏：Grafana 或 PowerBI 視覺化展示全員回報率。
📈 預期效益與 KPI 衡量

數位化上線成效指標：

  • 晨間對齊效率提升 40%：杜絕口頭催收，透過看板一目了然。
  • 會議執行落實率達 95%：後台追蹤每個 Action Item 不遺失。
  • 市場情報轉化率提高：讓鋰電情報及時反哺至廣告與業務宣傳。
